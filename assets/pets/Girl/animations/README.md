# Animation frames for Girl

Put numbered PNGs here to replace procedural motion:

```
animations/
  idle/
    001.png
    002.png
    ...
  walk/
  look/
  stretch/
  yawn/
  sleep/
  click/
  happy/
  talk/
```

Transparent PNGs, same canvas size preferred.
If a folder is missing, the pet falls back to procedural motion.
